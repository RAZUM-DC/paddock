# tests

e2e на puppeteer-core против живой морды (нужен Chrome; `CHROME=` — путь, по умолчанию macOS).

| файл | что | запуск |
|---|---|---|
| `ui-tour.mjs` | 18 шагов по всей морде: вход, ответ, правка, пикер, инструменты, лимиты, папки, все вкладки настроек, файлы, раскладки; скриншоты; убирает за собой тестовые чаты | `HUB_PASS=… node tests/ui-tour.mjs /tmp/tour` |
| `grid-edges.mjs` | 22 крайних случая сетки окон: упоры границ 20/80, двойной клик, перетаскивание во время ответа, бросок мимо, 4→1→4, Alt+N, перезагрузка, закрытие, 1280×720 | `HUB_PASS=… node tests/grid-edges.mjs` |

`HUB_URL` (по умолчанию `http://localhost:8088`), `HUB_EMAIL` (по умолчанию `valera@hub.local`).
