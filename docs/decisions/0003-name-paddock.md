# Название — Paddock

Харнессов будет несколько, поэтому имя не про Codex. Paddock — загон у ипподрома:
у каждого своё стойло (контейнер), лошадей (харнессы) можно менять, трибуна (морда) одна.
Рабочая папка и compose-проект на сервере пока называются `codex-hub` — переименуем при
переезде на новую схему харнессов, чтобы не трогать работающий стенд.
